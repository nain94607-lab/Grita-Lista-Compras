# 🛒 Lista de Compras - React Native + Expo

Aplicación móvil sencilla para gestionar una lista de compras de forma interactiva, desarrollada con React Native, Expo y Bun.

## Requisitos previos

Antes de arrancar, asegúrate de tener lo siguiente en tu compu y celu:

1. **Bun** instalado (puedes verificarlo en la terminal con `bun --version`).
2. La aplicación **Expo Go** descargada en tu teléfono (disponible gratis en Google Play Store o Apple App Store).
3. Tu computadora y tu celular conectados a la **misma red Wi-Fi**.

---

## Instalación y ejecución paso a paso

1. **Cloná el repositorio en tu computadora:**
   ```bash
   git clone [https://github.com/nain94607-lab/Grita-Lista-Compras.git](https://github.com/nain94607-lab/Grita-Lista-Compras.git)
   cd Grita-Lista-Compras
   bun install
   bun start
   ```
